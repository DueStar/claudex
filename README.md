# spawn

**한국어** · [English](README.en.md) · [日本語](README.ja.md)

Claude Code 세션을 포켓몬과 함께 쓰는 Windows 데스크톱 앱이에요. 세션마다 파티의 포켓몬이 하나씩 나가서 일하고, Claude가 일하는 동안 야생 포켓몬을 만나 도감을 채워요. 싸움은 없고 **수집**이 중심이에요.

> 비영리 팬 프로젝트예요. 포켓몬과 관련된 이름과 그림의 권리는 Nintendo / Creatures Inc. / GAME FREAK inc.에 있어요. 자세한 내용은 [NOTICE.md](NOTICE.md)를 봐 주세요.

## 무엇을 하나요

### 세션 = 포켓몬
- 처음 켜면 파티 6마리를 받아요. 1~9세대 스타팅 가운데 1마리와 일반 등급 5마리이고, 모두 Lv.5로 몬스터볼에 들어 있어요.
- **New session**을 누르고 파티에서 포켓몬을 고르면, 그 포켓몬이 새 Claude Code 세션을 맡아요. 파티 6마리가 모두 일하고 있으면 박스의 포켓몬이 조력자로 맡아서, 세션을 최대 12개까지 열 수 있어요.
- 세션은 자기 포켓몬을 기억해요. 이어하기를 하면 같은 포켓몬이 다시 나와요.
- 세션 이름은 더블클릭이나 ✎로 바꿀 수 있어요.
- 일하는 포켓몬은 언제든 잡은 다른 포켓몬으로 바꿀 수 있어요.

### 포획
- Claude가 도구를 한 번 쓸 때마다 한 걸음이에요. 도구 없이 1분 넘게 생각하거나 글을 써도 한 걸음이에요. 걸음마다 1% 확률로 야생 포켓몬을 만나고, 걸음이 몰리면 차례대로(8초 간격) 처리돼요.
- 매일 첫 세션에는 아직 못 잡은 포켓몬이 꼭 한 마리 나와요(출석 조우).
- 만나는 곳은 쓰는 도구로 정해져요. Edit은 풀숲, Bash는 동굴, Read는 숲이고, 밤에는 고스트·악·에스퍼 타입이 더 잘 나와요.
- 잡히면 화면 맨 위에 알림이 떠요. 어떤 요청에서 어떤 도구를 쓰다 잡았는지와 어떤 볼에 잡혔는지가 같이 남아요.

| 등급 | 만날 확률 | 기준 |
|---|---|---|
| 일반 | 74% | 그 밖의 포켓몬 |
| 희귀 | 21% | 공식 포획률 45 이하 (스타팅, 600족, 화석 등) |
| 준전설 | 3.6% | PokeAPI `is_legendary` 중 표지 전설이 아닌 포켓몬 |
| 전설 | 1.0% | 표지 전설 |
| 환상 | 0.4% | PokeAPI `is_mythical` |

- 색이 다른 포켓몬(✦)이 나올 확률은 1/4096이고, 아직 못 잡은 종은 더 잘 나와요.

### 개체
- 포켓몬마다 성별(종별 공식 성비)과 성격(공식 25종)이 있어요.
- 본가 진화 레벨에 진화해요(파이리 16, 리자드 36 등). 성장은 포켓몬마다 따로 쌓여요.
  - 친밀도 진화: 내가 레벨을 20 올린 뒤 다음 레벨업에 진화해요.
  - 통신 진화: 교체나 교환을 한 뒤 다음 레벨업에 진화해요.
  - 이브이: Lv.30부터 상황에 따라 에브이(친밀도·낮), 블래키(친밀도·밤), 리피아(숲), 글레이시아(동굴·밤), 그 밖에는 돌 진화와 님피아 중 하나로 진화해요.
  - 진화의 돌 진화는 Lv.30(두 번째 진화는 40)이에요.
- 한 번 잡은 종은 다시 만날 확률이 잡을 때마다 10%씩 줄어들어요(0.9, 0.81, …). 줄어든 몫은 같은 등급의 다른 포켓몬이 나눠 가져요.
- 잡힌 볼은 정해진 확률로 골라져요. 희귀도는 게임에서 얼마나 구하기 쉬운지를 기준으로 나눴어요.

| 볼 등급 | 확률 | 볼 |
|---|---|---|
| 흔한 볼 | 60% | 몬스터볼 32, 슈퍼볼 18, 하이퍼볼 10 |
| 특수 볼 | 29.4% | 프리미어 4, 네트·다이브·네스트·리피트·타이머·다크·퀵·힐 각 3, 럭셔리 1.4 |
| 규격 외 볼 | 8.4% | 스피드·레벨·루어·헤비·러브러브·프렌드·문볼 각 1.2 |
| 한정 볼 | 2.0% | 사파리 1.2, 울트라볼 0.8 |
| 마스터볼 | 0.2% | 전설·환상을 잡을 때는 1% |

- 컴퍼티션볼·파크볼·드림볼·프레셔스볼은 게임에서처럼 이벤트로만 받는 볼이라 야생 포획에서는 나오지 않아요.
- 상황이 맞으면 그 볼이 더 잘 나와요. 예를 들어 밤이나 동굴(Bash)에서는 다크볼, 검색 도구를 쓰다 잡으면 루어볼, 울트라비스트는 울트라볼, 오래 함께 일한 포켓몬과는 럭셔리·프렌드볼이 잘 나와요. 전체 조건은 `server/pokedex.js`의 `ballBoosts`에 있어요.
- 레벨: 야생 포켓몬은 Lv.1~55로 만나요. 함께 일한 시간으로 레벨이 올라요. 처음엔 20분, 높은 레벨일수록 길어져 60분마다 1레벨이고, Lv.100까지 약 55시간이에요.

### 도감과 박스
- **도감**: 1025종 전체를 세대·등급별로 볼 수 있어요. 잡았지만 아직 열어보지 않은 포켓몬에는 빨간 점이 붙어요.
- **박스**: 최대 1200마리까지 들어가요. 정렬, 검색, 색이 다른 포켓몬 필터가 있고 파티와 자리 바꾸기와 놓아주기를 할 수 있어요. 꽉 차면 새로 잡은 포켓몬은 도감에만 등록되고 박사님께 보내져요.

### 앱
- **위젯 / 창 / 전체화면**: 위젯은 항상 위에 떠 있고, 창과 전체화면은 일반 창이에요. 전체화면은 작업 표시줄 위까지만 채워요.
- **터미널**:
  - Shift+Enter나 Ctrl+Enter로 줄바꿈해요.
  - 링크는 Ctrl+클릭으로 열려요.
  - 파일을 끌어다 놓으면 경로가 입력돼요.
  - 위쪽 탭을 끌어서 세션 순서를 바꿀 수 있어요.
- **세션 다시 열기**: 앱을 닫을 때 열려 있던 세션이 다음에 켤 때 다시 열려요(설정에서 끌 수 있어요).
- **한도**: 5시간·주간 한도와 리셋 시각을 보여줘요.
- **구글 로그인**(선택): 도감이 클라우드(Supabase)에 저장돼요.
- **업데이트**: 새 버전이 나오면 위젯 상단에 업데이트 버튼이 떠요. 앱 부분만 받아서 재시작해요.

## 설치

1. [Releases](https://github.com/DueStar/spawn/releases/latest)에서 `spawn-<버전>-win-x64.zip`을 받아 원하는 곳에 풀어요.
2. `win-unpacked\spawn.exe`를 실행해요.

필요한 프로그램이 없으면 앱이 설치 링크를 보여줘요.
- [Claude Code](https://docs.claude.com/en/docs/claude-code/setup) (로그인된 상태)
- [Git for Windows](https://git-scm.com/downloads/win): Claude Code가 Git Bash를 써요.

Python 같은 다른 프로그램은 필요 없어요. 세션 기록(훅)은 spawn이 직접 돌려요.

> 코드 서명이 아직 없어요. SmartScreen 경고가 뜨면 **추가 정보 → 실행**을 눌러 주세요. Windows 11의 스마트 앱 컨트롤이 켜져 있으면 실행이 막혀요.

포켓몬 그림은 앱에 들어 있지 않아요. 처음 볼 때 [PokeAPI 이미지 저장소](https://github.com/PokeAPI/sprites)에서 받아 `%USERPROFILE%\.spawn\sprites`에 저장하고, 그다음부터는 저장된 파일을 써요.

## 어떻게 동작하나요

```
spawn (Electron)
 ├─ 터미널 (node-pty + xterm.js) ── claude --session-id … --settings <spawn 전용 훅>
 │                                        │ 훅·상태줄
 ├─ 로컬 서버 127.0.0.1:3334 <────────────┘
 │    ├─ 세션 상태, 한도
 │    ├─ 게임 (server/pokedex.js → ~/.spawn/pokedex.json)
 │    ├─ 포켓몬 그림 (server/sprites.js, 처음 쓸 때 받아서 저장)
 │    └─ 클라우드 동기화 (server/cloud.js, Supabase)
 └─ 위젯 / 도감 / 박스 / 알림 창 (React)
```

- **훅은 spawn이 띄운 세션에만 걸려요**: Claude Code의 전역 설정(`~/.claude/settings.json`)은 건드리지 않아요.
- **서버는 로컬에서만 열려요**: 서버는 `127.0.0.1`에서만 열리고, 바꾸는 요청에는 `~/.spawn/auth-token`이 필요해요.
- **업데이트는 서명을 확인해요**: 앱은 릴리스 키로 서명된 `latest.json`만 받아들여요.
- **데이터 폴더**: 이 앱은 1.3.35까지 Claudex라는 이름이었어요. 그때 쓰던 `~/.claudex`(1.3.7까지는 `~/.agent-office`)와 설정 폴더 `%APPDATA%Claudex`는 spawn 첫 실행 때 `~/.spawn`, `%APPDATA%spawn`으로 복사돼요. 옛 폴더는 그대로 남아 있으니, 잘 돌아가는 걸 확인한 뒤 지워도 돼요. 예전 환경 변수 이름(`CLAUDEX_PORT`, `CLAUDEX_HOME` 등)도 계속 읽어요.
- **로그**: 트레이 메뉴 "로그 폴더 열기"에서 `spawn.log`를 볼 수 있어요.
- **로그인 토큰은 서버에만 있어요**: 클라우드 로그인 토큰은 화면 쪽으로 넘어가지 않아요.

## 내 Claude Code 훅과 같이 쓰기

spawn은 Claude Code를 `claude --session-id <id> --settings %APPDATA%\spawn\session-settings.json`으로 띄워요. 이 파일에 spawn 훅(이벤트 16종)과 상태줄이 들어 있고, 앱을 켤 때마다 새로 써요. `~/.claude/settings.json`이나 프로젝트의 `.claude/` 설정은 건드리지 않아요.

- **내 훅은 그대로 돌아요**: Claude Code는 여러 설정에 있는 훅을 합쳐서 실행해요. spawn 세션에서는 내 훅과 spawn 훅이 같이 돌아요. spawn 훅은 아무것도 출력하지 않고 항상 성공(종료 코드 0)으로 끝나서, 내 훅이 내린 권한 응답이나 프롬프트에 붙이는 내용을 바꾸지 않아요. 도구 호출 훅 세 가지(PreToolUse·PostToolUse·PostToolBatch)는 `async`로 걸려 있어서 Claude가 기다리지 않아요. 나머지는 spawn 서버가 꺼져 있으면 최대 1초 기다리고 넘어가요.
- **상태줄은 spawn 것이 보여요**: 상태줄은 하나만 쓸 수 있어요. Claude Code 설정 우선순위에서 `--settings`가 사용자·프로젝트 설정보다 앞서기 때문에, spawn 세션에서는 내 상태줄 대신 spawn 상태줄(`모델 · ctx 42% · $1.23`)이 보여요. spawn은 이 상태줄로 컨텍스트 사용량과 5시간·주간 한도를 받아요. spawn 밖의 세션에서는 내 상태줄이 그대로 나와요.
- **spawn이 넣는 환경 변수**: spawn 터미널의 Claude Code 세션에만 들어가요. 내 훅에서 `SPAWN_SESSION_ID`가 있으면 spawn 안에서 도는 세션이에요.

| 변수 | 값 |
|---|---|
| `SPAWN_SESSION_ID` | 그 터미널의 세션 id. `/clear`로 대화가 바뀌어도 그대로예요 |
| `SPAWN_LINK_FILE` | `%APPDATA%\spawn\session-links\<세션 id>`. spawn 훅이 SessionStart마다 지금 대화 id를 여기에 써 두고, 세션을 다시 열 때 그 대화로 이어가요 |

- **빠지는 환경 변수**: 세션 환경에서 `CLAUDECODE`, `CLAUDE_PID`, `CLAUDE_CODE_`로 시작하는 변수는 빼요. Claude Code 안에서 spawn을 켰을 때 새 세션이 그 세션의 하위 세션으로 잡히지 않게 하려는 거예요. 그래서 `CLAUDE_CODE_…` 변수를 시스템 환경 변수로 두었다면 spawn 세션에는 전달되지 않아요.
- **spawn 밖의 세션은 세지 않아요**: 걸음·포획·한도는 spawn 터미널에서 연 세션에서만 들어와요. 다른 터미널이나 IDE에서 연 Claude Code 세션에는 spawn 훅이 없어서 포켓몬이 걷지 않아요.

## 저장하는 것과 보내는 것

### 이 PC에 저장하는 것

`~/.spawn`은 `%USERPROFILE%\.spawn`이에요(`SPAWN_HOME`으로 바꿀 수 있어요).

| 위치 | 내용 |
|---|---|
| `~/.spawn/pokedex.json` | 게임 전체: 파티, 박스, 도감, 기록. 포획 기록에는 잡은 프로젝트 폴더 이름, 쓰던 도구와 인자 앞부분(예: Bash 명령 앞 32자), 그때 요청의 앞 40자가 들어 있어요 |
| `~/.spawn/agents.json` | 지금 열려 있는 세션 상태(폴더, 모델, 마지막 요청·답변 앞 200자 등). 서버가 다시 켜져도 이어가려고 둬요 |
| `~/.spawn/usage-limits.json` | 마지막으로 받은 5시간·주간 사용량과 리셋 시각 |
| `~/.spawn/auth-token` | 로컬 서버 토큰(무작위 값). 훅과 화면이 서버에 요청할 때 써요 |
| `~/.spawn/cloud-session.json` | 구글 로그인 세션. 로그인했을 때만 있어요 |
| `~/.spawn/sprites/` | 받아 둔 포켓몬 그림 |
| `%APPDATA%\spawn\settings.json` | 설정 |
| `%APPDATA%\spawn\window-state.json` | 창 위치·크기·모드, 세션 이름 |
| `%APPDATA%\spawn\open-sessions.json` | 다음에 켤 때 다시 열 세션(세션 id, 폴더, 도구) |
| `%APPDATA%\spawn\session-links\` | 터미널마다 지금 이어지는 대화 id |
| `%APPDATA%\spawn\session-settings.json` | spawn 세션에 주는 훅·상태줄 설정 |
| `%APPDATA%\spawn\logs\spawn.log` | 앱과 로컬 서버의 로그 |

- 이어하기 목록을 만들려고 `~/.claude/projects`(대화 기록)와 `~/.claude/sessions`(실행 중인 세션)를 읽기만 해요.
- 로컬 서버는 `127.0.0.1`에서만 열리고, 훅과 화면의 요청은 `auth-token`으로 서명하거나 확인해요.
- 설정의 "프롬프트 숨기기"를 켜면 화면에서 가리고, 클라우드에 올리는 게임 사본에서도 요청 내용과 도구 인자를 빼요(도구 이름만 남아요). 이 PC의 `pokedex.json`에는 그대로 남아요.

### PC 밖으로 나가는 것

| 언제 | 어디로 | 무엇을 |
|---|---|---|
| 구글 로그인을 했을 때, 잡기·진화 같은 기록이 바뀌면(최대 30초에 한 번) | Supabase | 사용자 id, 표시 이름(구글 이름, 없으면 이메일), 잡은 종 수·본 종 수, 게임 사본. 사본에서 이 PC만 쓰는 값(세션 배정, 프로젝트 목록, 오늘 포획 수, 세션 시작 시각)은 빼고 기록은 최근 200건만 올려요. 포획 기록 안의 프로젝트 폴더 이름은 사본에 남아요. 도구 인자 앞부분과 요청 앞 40자도 남는데, "프롬프트 숨기기"를 켜면 빼고 올려요. 행 수준 보안(RLS)으로 본인만 읽고 써요 |
| 랭킹을 볼 때 | Supabase | 어느 순위표인지만 보내요. 로그인 전에도 볼 수 있고, 로그인했으면 내 순위를 찾으려고 로그인 정보가 같이 가요. 받는 건 공개한 참여자의 닉네임, 대표 포켓몬, 숫자뿐이에요 |
| 랭킹에 참여하거나 바꿀 때 | Supabase | 닉네임, 공개 여부, 대표 포켓몬 번호. 순위 숫자(도감 수, 색이 다른 포켓몬 수, 전설·환상 수, 이번 주 포획)는 앱이 보내지 않고 Supabase가 올라온 게임 사본에서 계산해요. 구글 이름과 이메일은 랭킹에 나오지 않아요 |
| 포켓몬 그림을 처음 볼 때 | `raw.githubusercontent.com`(PokeAPI 그림), `img.pokemondb.net`(박스 아이콘) | 그림 주소 요청만 |
| 켠 뒤 15초, 그다음 30분마다 | GitHub Releases(`github.com`, 안 되면 `api.github.com`) | 새 버전 확인(`latest.json`). 업데이트를 받을 때는 앱 파일을 내려받아요 |
| 의견 보내기에서 「보내기」를 눌렀을 때만 | Supabase(`feedback` 표, 쓰기만 되고 API로는 아무도 읽을 수 없어요) | 쓴 글, 앱 버전, 시스템(Windows 버전), 언어, 그때 화면 이름과 창 크기, 위치를 찍었다면 그 요소 이름. "이 부분 화면도 같이 보내기"를 켰을 때만 그 부분 그림(비공개 저장소). 누가 보냈는지(계정)는 보내지 않아요 |

- 이 밖에 사용 통계나 오류 보고를 보내는 코드는 없어요.

## 개발

```bash
npm install
npm run dev:electron        # 개발 실행
npx vitest run tests/pokedex.test.ts tests/sprites.test.ts tests/theme.test.ts
npm test                    # Windows에서도 전부 통과해야 해요
node scripts/release.mjs             # 빌드 (release/), 노트는 CHANGELOG.md의 "### <버전>"
node scripts/release.mjs --publish   # 점검 후 GitHub 릴리스까지 (서명 키 필요)
```

- **빌드할 때 받는 그림**: `tools/fetch-balls.mjs`가 볼 그림을 받아요. `tools/build-icons.py`는 앱 아이콘을 만들어요.
- **저장소에 없는 것**: 포켓몬·볼 그림은 저장소에 넣지 않아요(`.gitignore`).
- **시험 실행**: 실제 데이터를 건드리지 않으려면 `SPAWN_HOME=<임시 폴더> SPAWN_PORT=3344`로 실행하세요.

```
spawn/
├── electron/      # 앱: 창, 터미널, 업데이트, 트레이
├── server/        # 로컬 서버: 게임, 그림, 클라우드, 세션
├── src/           # 화면: Widget, 도감, 박스, 알림
├── hooks/         # Claude Code 훅과 상태줄
├── tools/         # 데이터·그림 준비 스크립트
├── scripts/       # 릴리스 스크립트
└── supabase/      # 클라우드 테이블 (RLS)
```
