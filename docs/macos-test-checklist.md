# spawn Mac 테스트 체크리스트 (약 15분)

spawn의 첫 번째 Mac 버전을 직접 써 봐 주셔서 고마워요. 개발자가 아니어도 괜찮아요. 아래 순서대로 따라 하면서 각 단계의 "이렇게 보이면 정상"과 비교해 주세요. 다르면 화면 캡처(⌘⇧4 → 영역 선택)나 로그 파일을 보내 주시면 돼요.

**시간이 없으면 별표(★) 네 개만 먼저 해 주세요.** 1번(첫 실행), 6번(한글 입력), 8번(⌘W), 19번(업데이트)이에요.

용어 두 가지만 알아 두세요.
- **세션**: 앱 안에서 Claude를 하나 띄운 터미널 탭이에요.
- **메뉴 막대**: 화면 맨 위 줄, 시계와 와이파이 아이콘이 있는 곳이에요. spawn 아이콘(몬스터볼)도 여기에 생겨요.

## 이미 정해진 것
- Mac에서는 앱 오른쪽 위의 전체화면/창 모드 버튼이 없어요. 신호등 버튼과 제목줄 더블클릭으로 해요(11, 12번).
- Mac 버전이 처음 정식으로 나갈 때의 버전은 **1.4.0**이에요. 지금 테스트하는 건 그 전의 테스트 버전이에요.
- 아직 Apple 개발자 서명 전이라 처음 한 번은 "그래도 열기"가 필요해요(1번).

## A. 설치와 첫 실행

### 1. ★ 내 Mac에 맞는 파일 받기, 설치, 첫 실행
1. 왼쪽 위 Apple 메뉴 → **이 Mac에 관하여**를 열어요. "칩"에 **Apple M1/M2/M3/M4**가 보이면 Apple Silicon, **Intel**이 보이면 Intel이에요.
2. 안내받은 링크에서 내 Mac에 맞는 파일을 받아요. 이름에 `mac-arm64`(Apple Silicon) 또는 `mac-x64`(Intel)가 들어 있어요.
3. 받은 zip을 더블클릭해서 풀면 `spawn` 앱이 나와요. 이걸 **응용 프로그램** 폴더로 끌어다 놓아요. (다운로드 폴더에서 바로 열지 마세요. 업데이트 테스트가 달라져요.)
4. 응용 프로그램의 spawn을 더블클릭해요. "확인되지 않은 개발자" 또는 "열 수 없음" 경고가 나오는 건 **예상된 동작**이에요. 아직 Apple 개발자 서명 전 버전이라서 그래요. 창을 **완료**(또는 **취소**)로 닫아요.
5. **시스템 설정 → 개인정보 보호 및 보안**으로 가서 아래로 내리면 "spawn이(가) 차단되었습니다" 문구와 **그래도 열기** 버튼이 있어요. 눌러요. 암호나 Touch ID를 물으면 입력해요.
6. 한 번 더 뜨는 창에서 **열기**를 눌러요. 이 과정은 **처음 한 번만** 하면 돼요.

이렇게 보이면 정상: spawn 창이 열려요. 다음부터는 경고 없이 열려요.
문제가 있으면: 4~6번 중 어디서 막혔는지 화면 캡처를 보내 주세요. "그래도 열기"가 안 보이면 칩 종류와 macOS 버전도 알려 주세요.

### 2. 준비 항목 확인
앱 첫 화면의 **준비 카드**("시작하기 전에 설치가 필요해요")를 봐요.
이렇게 보이면 정상: **Claude Code**가 설치되어 있으면 통과로 보여요. **Git**은 Mac에서 "선택 사항이에요"로 보이고, 없어도 막지 않아요. Git 때문에 "개발자 도구를 설치하시겠습니까?" 창이 뜨면 **있어선 안 되는 동작**이니 꼭 알려 주세요.
Claude Code가 없다고 나오면 카드의 **설치 페이지** 안내대로 설치하고 **다시 확인**을 눌러요. (이미 설치했는데 "없음"이라고 나오면 그것도 문제예요.)
문제가 있으면: 준비 카드 화면 캡처.

### 3. Claude 로그인과 첫 세션
1. 새 세션을 열어요. **다른 폴더에서 새 세션**(폴더 아이콘)을 누르고 `문서` 안의 아무 폴더나 골라요.
2. macOS가 "spawn이(가) '문서' 폴더의 파일에 접근하려고 합니다" 같은 창을 띄우면 **허용**을 눌러요. 문서, 데스크탑, 다운로드 폴더는 처음 한 번씩 이 창이 나오는 게 **정상**이에요.
3. Claude가 로그인을 요구하면 화면 안내대로 브라우저에서 로그인을 마쳐요.

이렇게 보이면 정상: 세션 탭이 생기고 Claude 시작 화면이 보여요.
문제가 있으면: 화면 캡처. 세션이 아예 안 뜨면 로그 파일(아래 "로그 파일 가져오는 법").

## B. 터미널 기본

### 4. Claude 대답 받기
세션 입력창에 `이 폴더에 무슨 파일이 있어?`를 입력하고 Enter를 눌러요.
이렇게 보이면 정상: Claude가 답을 써 내려가요. 글자가 깨지거나 겹치지 않아요.
문제가 있으면: 화면 캡처.

### 5. 복사와 붙여넣기 (⌘C / ⌘V)
1. Claude 답변의 일부를 마우스로 드래그해서 선택하고 **⌘C**. 입력창을 클릭하고 **⌘V**.
2. 터미널 밖 입력칸에서도 해 봐요. 예: 세션 이름을 바꾸는 칸(세션 탭의 이름을 더블클릭), 설정의 입력칸.

이렇게 보이면 정상: 터미널에서도 입력칸에서도 복사, 붙여넣기가 돼요.
문제가 있으면: 터미널과 입력칸 중 어디서 안 되는지 메모.

### 6. ★ 한글 입력 (조합 중 Enter)
1. 세션 입력창에 `안녕하세요`를 치고, **마지막 글자를 막 입력해서 아직 조합 중일 때(글자에 밑줄이 남아 있을 때)** 바로 Enter를 눌러요.
2. `테스트`, `한글입력` 등으로 몇 번 더 해 봐요. 빠르게도, 천천히도요.

이렇게 보이면 정상: 메시지가 **한 번만** 전송되고, 마지막 글자가 빠지거나 두 번 들어가지 않아요. 입력이 끝나기 전에 먼저 전송되지도 않아요.
문제가 있으면: 어떤 글자를 쳤는지와 결과(글자가 사라짐 / 두 번 보내짐 / 너무 일찍 보내짐 / Enter가 안 먹음)를 메모해 주세요. 화면 캡처도 좋아요.

### 7. Ctrl+C로 멈추기
Claude에게 `1부터 200까지 한 줄씩 써 줘`처럼 긴 일을 시키고, 일하는 중에 **Ctrl+C**(⌘ 말고 control 키)를 눌러요.
이렇게 보이면 정상: 작업이 중단돼요.
문제가 있으면: 메모만 해 주세요.

## C. 단축키

### 8. ★ 탭 닫기 ⌘W (가장 중요해요)
세션을 두 개 만들고(⌘T), 한 세션에서 **⌘W**를 눌러요.
이렇게 보이면 정상: **그 세션 탭만** 닫히고 앱 창은 그대로 남아요.
**이러면 문제**: 앱 창 전체가 닫히거나 사라져요. "탭만 닫힘" / "창 전체 닫힘" 중 어느 쪽이었는지 꼭 적어 주세요. 가장 중요한 정보예요. (창이 닫혔다면 메뉴 막대의 spawn 아이콘으로 다시 열 수 있어요.)

### 9. 나머지 단축키
큰 창(창 모드)에서 하나씩 눌러 보세요. 위쪽 보기 탭에 마우스를 올리면 단축키가 말풍선으로 나와요.

| 키 | 이렇게 보이면 정상 |
|---|---|
| ⌘1 ~ ⌘5 | 위쪽 보기가 순서대로 바뀌어요: 터미널, 도감, 박스, 기록, 랭킹 |
| ⌘T | 새 세션이 열려요 |
| ⌘⇧[ 와 ⌘⇧] | 세션 탭이 이전, 다음으로 옮겨가요 |
| ⌥⌘← 와 ⌥⌘→ | 보기가 이전, 다음으로 바뀌어요 |
| ⌘F | 터미널의 찾기가 열려요 |
| ⌘+ (⌘=) 와 ⌘- | 터미널 글자가 커지고 작아져요. ⌘0은 원래 크기예요 |
| 터미널 위에서 트랙패드 두 손가락 벌리기/오므리기 | 글자 크기가 **부드럽게 한 단계씩** 변해요. 갑자기 확 커지거나 작아지면 문제예요 |

문제가 있으면: 어떤 키가 반응이 없었는지, 엉뚱한 일이 일어났는지 메모.

## D. 창과 화면 모드

### 10. 신호등 버튼 (빨강, 노랑, 초록)
1. 큰 창 왼쪽 위 모서리의 빨강/노랑/초록 동그란 버튼을 봐요.
2. 사이드 패널(세션 목록이 있는 옆 패널)을 **펼친 상태**와 **접은 상태**에서 각각 그 모서리를 캡처해 보내 주세요. (캡처 2장)

이렇게 보이면 정상: 세 버튼이 spawn 로고나 탭과 **겹치지 않아요**. 로고는 버튼 오른쪽에 있어요.
문제가 있으면: 위 캡처 두 장이 가장 큰 도움이 돼요.

### 11. 오른쪽 위 버튼이 없는지 확인
창 오른쪽 위를 봐요.

이렇게 보이면 정상: 최소화/전체화면/닫기 모양의 버튼이 **없어요**. (Windows 버전에는 있지만 Mac에서는 신호등 버튼이 그 역할을 해요.)
참고: Mac에서는 오른쪽 위의 앱 자체 전체화면/창 모드 버튼이 **일부러 숨겨져 있어요**. 안 보여도 문제가 아니에요. 대신 아래 12번의 두 방법으로 화면을 채워요.
문제가 있으면: 화면 캡처.

### 12. 화면 채우기 두 가지: 초록 버튼과 제목줄 더블클릭
전체화면은 아래 두 방법으로 해요. **둘 다 해 보고, 각각 무슨 일이 일어났는지 적어 주세요.**
1. 초록 버튼을 눌러요. 그다음 다시 눌러 되돌려요.
2. 창 맨 위 빈 곳(제목줄)을 **더블클릭**해요. 한 번 더 더블클릭해요. (메뉴 막대의 **창 → 확대/축소**(Zoom)도 같은 동작이에요. 이것도 한 번 눌러 보세요.)

이렇게 보이면 정상: 초록 버튼은 macOS 기본 전체화면(별도 화면 공간)으로 들어가고, 다시 누르면 돌아와요. 더블클릭과 확대/축소는 화면을 채우고, 다시 하면 원래 크기로 돌아와요. 어느 쪽이든 앱이 멈추거나 창이 사라지지 않아요.
문제가 있으면: 어떤 동작에서 무엇이 일어났는지(채워짐 / 안 채워짐 / 안 돌아옴) 메모.

## E. 위젯 모드

### 13. 위젯 모드와 Dock 아이콘
1. 큰 창 위쪽의 **위젯 모드 켜기** 버튼(마우스를 올리면 "위젯으로 작게 (항상 위)")을 눌러요.
2. 위젯이 작게 떠 있는 동안 **Dock을 봐요**. 그다음 위젯의 **펼치기** 버튼으로 큰 창으로 돌아와 Dock을 다시 봐요.
3. 위젯 모드에서 지시하기 입력칸을 클릭해 글자를 입력하고, 글자를 선택해 **⌘C**, 다른 곳에 **⌘V**를 해 봐요.
4. 위젯을 띄운 채 **Mission Control(F3)이나 세 손가락 쓸기**로 다른 데스크탑(Space)으로 넘어가 봐요.

이렇게 보이면 정상: 위젯 모드에서는 Dock의 spawn 아이콘이 사라지고, 큰 창으로 돌아오면 다시 나타나요. (모드가 바뀔 때 아이콘이 한 번 깜빡이는 건 괜찮아요.) 위젯 입력칸에서도 ⌘C, ⌘V가 돼요. 위젯은 다른 데스크탑으로 가도 같이 따라와요.
참고: 위젯 모드에서는 화면 위 메뉴 막대에 spawn 메뉴가 안 보여요. 알려진 부분이라, 복사/붙여넣기가 **안 되면** 꼭 알려 주세요.
문제가 있으면: Dock이 안 사라짐 / 안 돌아옴 / 복붙 안 됨 / 위젯이 안 따라옴 중 해당하는 것을 메모.

### 14. 포켓몬 잡았을 때 알림 (토스트)
세션에서 Claude 작업을 몇 번 시키다 보면 포켓몬을 잡았다는 작은 알림이 화면에 떠요. 바로 안 나오면 15, 16번을 하는 동안 지켜봐 주세요.
이렇게 보이면 정상: 작은 알림창이 화면 한쪽에 떠서 글이 잘 읽혀요. 타자 치던 창의 **입력 포커스를 뺏지 않아요**. 알림이 뜰 때 Dock 아이콘이 깜빡이거나 튀지 않아요.
문제가 있으면: 알림이 뜬 위치와 모습 캡처. 알림 때문에 타이핑이 끊겼다면 알려 주세요. 끝까지 안 나오면 "안 나옴"이라고만 적어 주세요.

## F. 메뉴 막대와 알림

### 15. 메뉴 막대 아이콘과 로그인 시 실행
1. 화면 위 메뉴 막대에서 spawn 아이콘을 찾아 클릭해요.
2. 메뉴를 확인해요. 항목: 맨 위 상태 줄, **보이기/숨기기**, **설정**, **업데이트 확인**, **로그 폴더 열기**, **spawn 끝내기**.
3. **설정 → 앱**에서 **로그인 시 실행**을 켰다가 꺼요.

이렇게 보이면 정상: 아이콘이 밝은 배경과 어두운 배경 모두에서 잘 보이고, 메뉴가 위 항목대로 나와요. 로그인 시 실행 스위치가 켜지고 꺼져요. (확인했으면 **꺼서** 되돌려 주세요. 시스템 설정 → 일반 → 로그인 항목에서도 확인할 수 있어요.)
문제가 있으면: 메뉴 캡처. 스위치가 바로 되돌아가면 알려 주세요.

### 16. 확인이 필요할 때 알림 (Dock 아이콘 튀기)
1. **설정 → 알림**의 **세션 알림**이 켜져 있는지 봐요. 처음 알림이 오면 macOS가 알림 허용을 물어요. **허용**해요.
2. Claude가 확인을 요구할 일을 시켜요. 예: `이 폴더에 test.txt 파일을 만들어 줘`. 보통 허락을 물어 와요.
3. 그 직후 **다른 앱(예: 브라우저)을 앞으로** 가져와서 spawn을 뒤에 두고 기다려요.

이렇게 보이면 정상: 알림이 뜨고, Dock의 spawn 아이콘이 위아래로 **튀어요**.
문제가 있으면: 알림이 안 뜸 / Dock이 안 튐을 구분해서 메모. (시스템 설정 → 알림 → spawn이 꺼져 있지 않은지도 봐 주세요.)

## G. 종료, 재시작, 로그아웃

### 17. 종료하고 다시 열기
1. 세션 두 개를 열어 둔 상태에서 **⌘Q**로 앱을 완전히 끝내요.
2. 응용 프로그램에서 spawn을 다시 열어요.

이렇게 보이면 정상: 종료가 몇 초 안에 끝나고, 다시 열면 아까의 세션들이 돌아와요.
문제가 있으면: 세션이 안 돌아오면 로그 파일.

### 18. Mac 로그아웃 (앱을 켜 둔 채로)
1. spawn을 연 채로 세션 하나를 열어 둬요.
2. Apple 메뉴 → **로그아웃**을 눌러요.
3. 다시 로그인하고 spawn을 열어요.

이렇게 보이면 정상: spawn 때문에 "앱이 로그아웃을 막고 있습니다" 같은 창이 뜨거나 로그아웃이 취소되지 않고 그대로 진행돼요. 다시 로그인한 뒤 spawn을 열면 세션이 돌아와요.
문제가 있으면: 로그아웃이 중간에 멈췄는지, 세션이 돌아왔는지 메모 + 로그 파일.

## H. 업데이트

### 19. ★ 앱 안에서 업데이트 (테스트 버전 A에서 B로)
처음 설치한 게 테스트 버전 A예요. 테스트 버전은 아직 공개 업데이트로 나오지 않아서, 개발자가 보내 준 B 파일을 **내 Mac의 폴더에 두고** 앱이 그 폴더를 보게 해서 업데이트해요. 개발자가 B 파일 두 개를 보내 주면 그때 해 주세요.

1. 개발자에게 B 파일 **두 개**를 받아요. 내 Mac이 Apple Silicon이면 이름에 `arm64`, Intel이면 `x64`가 들어간 것이에요.
   - `spawn-app-버전-mac-arm64.zip` (앱 업데이트 파일)
   - `latest-mac-arm64.json` (업데이트 안내 파일)
   - zip 파일은 **풀지 마세요**. 그대로 둬야 해요. Safari로 받으면 zip이 저절로 풀려 폴더가 되어 버릴 수 있어요. 그러면 개발자에게 메신저로 파일을 다시 받거나 Chrome으로 받아 주세요.
2. **터미널**을 열어요. (⌘스페이스를 누르고 `터미널`이라고 친 다음 Enter.)
3. 아래 한 줄을 그대로 복사해서 터미널에 붙여 넣고(⌘V) Enter를 눌러요.

   ```
   mkdir -p ~/spawn-update ~/.spawn && echo "$HOME/spawn-update" > ~/.spawn/update-dir && open ~/spawn-update
   ```

   빈 Finder 창이 하나 열려요. (홈 폴더의 `spawn-update` 폴더예요. 이 폴더 경로를 적어 둔 파일도 함께 만들어져서, 앱이 이제 이 폴더에서 업데이트를 찾아요.)
4. 1번에서 받은 **파일 두 개**를 방금 열린 Finder 창으로 끌어다 놓아요.
5. spawn을 **⌘Q로 완전히 끝냈다가** 응용 프로그램에서 다시 열어요.
6. 1분쯤 기다리면 위쪽에 **업데이트** 버튼이 보여요. (기다리기 싫으면 메뉴 막대의 spawn 아이콘 → **업데이트 확인**.) 버튼을 눌러요.
7. "받는 중"이 지나면 **재시작해서 적용** 버튼이 나와요. 눌러요. 앱이 스스로 꺼졌다가 다시 켜져요.
8. 끝나면 터미널에 아래 한 줄을 붙여 넣고 Enter를 눌러 원래대로 돌려 놓아요. (`spawn-update` 폴더는 휴지통에 버려도 돼요.)

   ```
   rm ~/.spawn/update-dir
   ```

이렇게 보이면 정상: 앱이 알아서 재시작하고, 위쪽의 버전 숫자(`spawn 1.x.x`)가 B의 버전으로 바뀌어요. 이번에는 "그래도 열기"를 **다시 하지 않아도** 돼요.
다운로드 폴더에서 바로 연 앱이라면 업데이트 대신 "맥: 앱을 응용 프로그램 폴더로 옮긴 뒤 업데이트해 주세요"라고 안내해야 정상이에요. 이 안내가 나오면 그것도 OK로 적어 주세요.
문제가 있으면: 막힌 단계의 캡처, 그리고 로그 파일. 6번에서 버튼이 안 나오면 4번의 Finder 창 캡처(파일 두 개가 보이게)도 보내 주세요. 재시작 후 앱이 안 열리면 `update.log`도 같이 보내 주세요(아래).

> 개발자 메모: B는 A보다 높은 버전으로 만들어요(mac.yml을 `version` 입력으로 실행). B의 CI 산출물에서 `spawn-app-<v>-mac-<arch>.zip`을 꺼내고, 같은 폴더에 `latest-mac-<arch>.json`을 `scripts/manifest.mjs`의 `writeManifest('darwin', arch, …)`로 써서 두 파일을 보내요. 이 폴더 경로(`~/.spawn/update-dir`, electron/updater.cjs `localUpdateDir`)로 받는 업데이트는 서명 검사를 하지 않아요. 그래서 서명 없는 manifest도 받아들여요. GitHub의 draft 릴리스는 앱이 보지 못해요.

## I. 의견 보내기와 링크

### 20. 의견 보내기
1. **설정 → 앱**의 **의견 보내기** 줄에서 **보내기** 버튼을 눌러요. "의견 보내기" 입력창이 떠요.
2. 칸에 `[mac test] 테스트 메시지예요`라고 적어요. (맨 앞의 `[mac test]`를 꼭 붙여 주세요.) 화면 위치 찍기는 건너뛰어도 돼요.
3. 창 아래의 **보내기** 버튼을 눌러요.

이렇게 보이면 정상: "보냈어요. 고마워요!"라는 문구가 나와요. 이 의견은 spawn 개발자만 볼 수 있는 비공개 저장소로 가요. 공개되지 않고, 로그인도 필요 없어요.
문제가 있으면: "보내지 못했어요. 복사해서 보내 주세요"가 나오면 문구를 그대로 메모하고 화면을 캡처해 주세요. (인터넷 연결을 먼저 확인해 주세요.)

### 21. 터미널의 파일 경로 링크
1. 세션에서 Claude에게 `내 문서 폴더의 전체 경로를 /Users/... 형태로 한 줄만 써 줘`라고 해요. (`~/something.txt` 같은 경로가 나와도 좋아요.)
2. 화면에 찍힌 경로 위에 마우스를 올리고 **⌘를 누른 채 클릭**해요.

이렇게 보이면 정상: 경로에 밑줄이 보이고, ⌘+클릭하면 그 파일이나 폴더가 열려요.
문제가 있으면: 어떤 경로가 안 열렸는지 메모.

## 로그 파일 가져오는 법
방법 1: 메뉴 막대의 spawn 아이콘 → **로그 폴더 열기**. Finder가 열려요.
방법 2: Finder에서 **이동 → 폴더로 이동**(⌘⇧G)을 열고 아래를 붙여 넣어요.

```
~/Library/Application Support/spawn/logs
```

보낼 파일:
- `spawn.log` (이번에 쓴 기록), 있으면 `spawn.old.log`
- 업데이트에 문제가 있었다면 한 칸 위 폴더(`~/Library/Application Support/spawn`)의 `update.log`

파일을 메일이나 메신저로 그대로 첨부해 주세요. 열어서 확인한 뒤 보내도 괜찮아요.

## 앱 완전히 지우기
테스트가 끝나면 아래를 지워 주세요. (Finder에서 이동 → 폴더로 이동, ⌘⇧G)

1. spawn 끝내기 (메뉴 막대 아이콘 → spawn 끝내기).
2. `/응용 프로그램/spawn`을 휴지통으로.
3. `~/Library/Application Support/spawn` 폴더를 휴지통으로. (설정, 로그, 저장된 세션이 들어 있어요.)
4. `~/.spawn` 폴더를 휴지통으로. (앞에 점이 있어 Finder에서 안 보일 수 있어요. ⌘⇧G로 이동하거나, Finder에서 ⌘⇧. 를 눌러 숨김 파일을 보이게 해요.)
5. 로그인 시 실행을 켜 두었다면 시스템 설정 → 일반 → 로그인 항목에 spawn이 없는지 확인해요.
6. 휴지통 비우기.

Claude Code 자체와 로그인(`~/.claude`)은 spawn과 별개라서 그대로 두면 돼요.

끝까지 해 주셔서 정말 고마워요!
